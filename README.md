# خبررسانی منطقه آزاد — پورتال خبری PHP + MySQL

پورتال اطلاع‌رسانی چندزبانه (فارسی/English/العربية) منطقه آزاد بوشهر — ساخته‌شده با PHP 8 و MySQL بدون هیچ کتابخانه بیرونی.

## بخش‌ها
اخبار (تیتر، آرشیو، مقاله، جستجو، دسته‌بندی سه‌زبانه) • اطلاعیه‌های رسمی (مناقصه/مزاید/اطلاعیه/فراخوان + وضعیت + کد رهگیری) • رویدادها (محل/موضوع) • چندرسانه ویدیویی و تصویری (مدت/تعداد عکس/دسته) • فرصت‌های سرمایه‌گذاری (حجم/IRR/دوره بازگشت/موقعیت/مشوق‌ها) • پالس منطقه (۵ شاخص با زیرشاخص‌ها) • پنل مدیریت کامل — همه محتواها سه‌زبانه (فا/EN/AR) با فونت‌های Vazirmatn/Estedad/Inter/Noto Kufi و تم روشن/تاریب (سرومه‌ای #2C3F5F، نارنجی #F1A334، آبی #0B68AD).

## نصب (XAMPP)
1. MySQL را از XAMPP اجرا کنید.
2. مرورگر: `http://localhost/bushehr-news/install.php` — اطلاعات دیتابیس و رمز مدیر را وارد کنید.
   (یا از خط فرمان: `php install.php` — رمز مدیر نمایش داده می‌شود)
3. پس از موفقیت، `install.php` و فایل `install.lock` را از سرور حذف کنید.

## دیتابیس
`bushehr_news` شامل جداول:
`admins`, `settings`, `categories(+tr)`, `articles(+tr, tags)`, `announcements(+tr)`, `events(+tr)`, `media_items(+tr)`, `investments(+tr)`, `pulse_metrics(+tr)`

پنل مدیریت: `http://localhost/bushehr-news/admin.php` (فارسی، با CSRF و رمز هش‌شده)

## استقرار روی هاست اشتراکی (cPanel/Liara و…)
1. فایل‌ها را در `public_html/bushehr-news` آپلود کنید.
2. یک دیتابیس MySQL بسازید و مشخصات را در `config.php` وارد کنید (یا در نصب‌کننده).
3. اجرای `install.php` یک‌بار، سپس حذف آن.

## امنیت
هیچ کلید یا رمزی در مخزن نیست؛ اطلاعات دیتابیس در `config.php` است و روی هاست واقعی دسترسی مستقیم به آن و `app.php` توسط `.htaccess` مسدود شده است. رمز مدیر به‌صورت هش‌شده (bcrypt) ذخیره می‌شود و فرم‌های پنل با توکن CSRF محافظت دارند.
